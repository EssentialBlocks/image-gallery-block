# Image Gallery Block

Impress your audience with a beautiful image gallery with lightbox — a standalone Gutenberg block plugin by [WPDeveloper](https://wpdeveloper.com), part of the [Essential Blocks](https://essential-blocks.com) family.

[![WordPress](https://img.shields.io/badge/WordPress-6.0%2B-blue.svg)](https://wordpress.org/plugins/image-gallery-block/)
[![PHP](https://img.shields.io/badge/PHP-7.4%2B-777bb4.svg)](https://www.php.net/)
[![License](https://img.shields.io/badge/license-GPLv3-green.svg)](https://www.gnu.org/licenses/gpl-3.0.html)

## Features

- **Completely customizable** — images, sizes, colors, spacing, and typography
- **Grid & masonry layouts** with responsive column controls
- **Lightbox** preview for full-size viewing
- **Category filters** with a selectable default filter
- **Image alt text** support for accessibility and SEO
- **Super light-weight** — no extra resources, optimized for fast loading and live editing

## Installation

### From the block editor

1. Open the WordPress Block (Gutenberg) editor
2. Search for **Image Gallery**
3. Install in one click

### Manual

1. Upload `image-gallery-block` to `/wp-content/plugins/`
2. Activate the plugin through the **Plugins** menu in WordPress
3. Follow the [documentation](https://essential-blocks.com/docs/)

## Development

```bash
npm install      # install dependencies
npm run start    # development build with watch
npm run build    # production build
```

Built with [`@wordpress/scripts`](https://developer.wordpress.org/block-editor/reference-guides/packages/packages-scripts/). Compiled assets land in `dist/`.
